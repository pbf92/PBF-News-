TITLE: Anthropic brings Skills over MCP to Claude and Claude Code in public beta
OUTLET: Crypto Briefing

MCP servers can now ship reusable workflow instructions alongside their tools, two years after the protocol first launched
Anthropic is expanding its Model Context Protocol. In a public beta announced on November 24, 2026, Claude and Claude Code now support Skills over MCP, an extension that lets servers deliver standardized workflow instructions together with the tools they already expose.
MCP servers are the connectors that let AI agents reach external tools and data, such as a company’s files, apps, or internal systems. They work like adapters that let Claude plug into software it was never built to talk to.
Until now, those servers mostly supplied capabilities. The agent got access to a tool but had to work out on its own how to string several tools together into a useful process.
The Skills extension changes that division of labor. A server can now package reusable, standardized instructions for how a workflow should run, and those instructions travel with the tools.
Two design choices stand out. Skills load on demand, so Claude only pulls in the instructions when a task calls for them. This matters because an AI model has a limited context window, the working memory it can hold at once, and filling it with unused instructions wastes space.
Skills also update automatically on the server side. Users don’t need to install anything separately, and when a company revises a workflow, the change reaches everyone connected to that server.
Claude Code users need version 2.1.331 or later to use the beta.
Tasks and Elicitation hit general availability
Skills weren’t the only item in the release. Anthropic also moved two other MCP features, Tasks and Elicitation, to general availability on the same day.

Tasks handles background jobs, the kind of longer-running work that shouldn’t freeze a conversation while it finishes. Elicitation covers moments where the agent needs input or a confirmation from the user before continuing.
Those features are available on Pro, Max, and Ultra subscription plans. Support for Team and Enterprise plans is described as upcoming, and Anthropic plans to add File Uploads shortly.
Two years of MCP growth
MCP launched on November 25, 2024, as an open standard for connecting AI models to outside systems.
It now counts more than 700 million monthly SDK downloads. SDK stands for software development kit, the prepackaged code developers use to build on a platform, so download volume is a rough gauge of how many builders are actively working with it.
The connector count has also passed 10,000.
Several well-known companies are among the early adopters. Shopify is using MCP for store design, HubSpot for customer onboarding, and Atlassian for supplying organizational context. Carta is expected to add integrations tied to equity workflows.
What this means for developers and the companies building on Claude
The biggest shift is about who owns the know-how. Previously, much of the logic for how an agent should complete a complex job lived with the user or the developer prompting it. With Skills, the company running the MCP server can encode its preferred process directly and keep it current from one place.
For developers, on-demand loading and server-side updates address two familiar problems: bloated context and version drift.
Some questions remain open. The feature is still in public beta, and Team and Enterprise access to Tasks and Elicitation has not arrived yet.
