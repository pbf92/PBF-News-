TITLE: GitHub deletes post promoting PS5-to-PC project AnyPS5 days after axing 3,000 GTA 6 PC port repos
OUTLET: TweakTown

The Microsoft-owned platform posted a message celebrating AnyPS5, a project that has passed 58,000 stars since its August launch, and tied it to GTA 6's release.

The post opened by calling the game's arrival one of the biggest weeks in gaming and open source on GitHub. It then asked followers, "Does changing where games run cross a legal line?" and signed off with "Happy GTA VImas." It was deleted soon after backlash, but not before people screenshotted it and reuploaded the video.
AnyPS5 isn't a traditional emulator. It converts PS5 executables into native Windows and Linux programs and swaps the console's system libraries for its own. It doesn't distribute proprietary game files and hasn't yet shown GTA 6 running on PC. The video in the post played up the GTA 6 angle, though. It featured a contributor's comment urging people to put their agents to work with only days left before the game launched.
Earlier this week, GitHub processed a DMCA notice from Take-Two that removed more than 3,000 repositories tied to an unofficial GTA 6 PC port, known as Leonida, which was based on a leaked Xbox build of the game.
One Reddit user said GitHub was "openly taunting Sony and Rockstar." Even the AnyPS5 subreddit seemed baffled, with a user asking if AI was running GitHub's socials. Others pointed out that Take-Two has been going after recompiled GTA 6 builds, so it's hard to imagine it enjoyed the post.
