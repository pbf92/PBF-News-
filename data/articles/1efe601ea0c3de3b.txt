TITLE: Anthropic now allows installing artifacts as desktop apps
OUTLET: TestingCatalog AI News

Claude artifacts can now be installed as desktop apps on Mac and Windows. Anthropic is rolling out the feature, called Install as app, as a beta in Claude for Mac and Windows. Users ask Claude to build an artifact, then choose Install as app from the artifact's title menu, a right-click menu, or the Share menu.
The result gets its own icon and opens in its own window, like any other app. On macOS, it lives in the Claude Apps folder in the home Applications folder, and on Windows, it appears in the Start menu or as a desktop shortcut.
An installed app can use Claude and the user's connectors the same way the original artifact does. If the user allows it, the app can send notifications, add a macOS menu bar item or a Windows system tray icon, listen for keyboard shortcuts, or float over other windows. Anthropic engineer Felix Rieseberg said the apps can use operating system APIs, and that no coding skills are required. He has used it to build terminals, file managers, video editors, communication tools, and desktop pets.
Users don't need to package or sign the app or set up an API key because it runs under their Claude account. Building the app and any requests it makes to Claude count toward plan usage limits. Edits to the underlying artifact automatically update the installed app.
Opening an app requires an internet connection and a signed-in Claude Desktop account. Anthropic's help center says version 6.28899.0 or later is required, and that installed apps are not available on Linux, the web, or mobile.
Install as app is rolling out in beta on Free, Pro, Max, Ultra, Team, and Enterprise plans. It is on by default for Team, with full computer access off until an admin enables it. On Enterprise, an owner must switch the feature on first. HIPAA-ready organizations and hybrid deployments cannot use it. Some artifacts cannot be installed, including Claude Docs, Slides, and Sheets, as well as legacy artifacts and live artifacts from Claude Cowork.
Each installed artifact runs in a standalone window, with permissions the user controls. By default, an installed app can only do what it could do in a browser. App permissions let it ask for notifications, global shortcuts, and always-on-top windows. Full computer access lets it ask to run programs and read, change, or delete files without asking each time. Anthropic does not review apps before they are installed, and a permission grant covers only the current version, so Claude asks again after every update, including the user's own edits. Full access can be given only to apps the user made or, on Team and Enterprise, apps made by people in the same organization.
Anthropic first offered artifacts as a way to share work such as a chart or a webpage. The company now presents them as tools people keep for everyday tasks, such as a meeting prep page that pulls from a calendar and email. Install as app is meant to let those tools open like the rest of the software on a Mac or Windows PC.
