Anthropic Debuts Claude Ship to Automate Pull Request Reviews and Merges
Anthropic rolled out a new product on Monday aimed at the part of software work that agentic coding has yet to automate: the pull request.
The tool, called Claude Ship, reviews proposed code changes, fixes problems it finds and decides which changes can be merged based on rules a team sets, the company said. It is available in beta on Claude Team and Enterprise plans for projects hosted on GitHub, and developers can try it on their own pull requests through a new /ship command in Claude Code.
Claude Ship is built from three agents that move a pull request through review, repair and an approval decision:
Anthropic said PR Steward is meant to assist developers rather than approve or merge changes on its own, and that it explains the edits it makes along with how to undo them. Claude Approvals can clear routine changes automatically when a team's policy permits, while sending higher-risk items to a human reviewer.
Teams can tune how much autonomy the system gets. Code Review runs at one of three depths — Quick, Standard or Deep — on a per-repository basis, and administrators choose when reviews run and how much the organization can spend. PR Steward accepts plain-language instructions in PR comments: developers can type @claude to redirect its work or @claude stop to make it stand down. Claude Approvals reads a policy file committed to the repository, which Anthropic describes as a smarter version of GitHub's CODEOWNERS file, and can weigh Code Review findings or custom classifiers written in natural language.
Anthropic is running Claude Ship on many of its own pull requests. On the Claude Code team, merged pull requests more than doubled between June and September while the share of changes that were reverted fell by more than 40%, the company said. Customers describe similar effects: Canada's TELUS said Code Review has caught real issues before human reviewers reached a pull request, while Carvana said teams in its pilot spend less time working through review feedback.
The company framed the launch as an attempt to close the gap between how quickly teams write code with AI agents and how quickly that code clears review. According to Anthropic, the goal is to "ship code as fast as teams write it."
Claude Ship is billed on token usage, separate from the subscription, so switching it on can add to an organization's costs. The amount depends on the number and size of pull requests covered, the review depth and how often reviews run; administrators can set monthly spending caps for Code Review and PR Steward. Claude Approvals carries no base charge, though classifiers in a policy are billed on the tokens they use, and a policy that uses Claude's review triggers a billed Code Review even in observe mode.
Anthropic recommends that most customers run the approval policy in observe-only mode first, then require Claude Approvals as a GitHub check once they trust it. The company also cautions that Claude Ship uses AI and may miss bugs, security vulnerabilities or other issues — a limitation that matters because the system can approve code when a team's policy allows it.
The launch comes as Anthropic deepens its presence in Japan, which it made its first Asia-Pacific office in October 2025. Japanese companies are among the customers Anthropic cites for Claude Code. Rakuten cut the average time to market for new features from 24 working days to five — a 79% reduction — according to an Anthropic case study. NEC plans to make Claude available to about 30,000 group employees, and Hitachi has said it will deploy the technology across roughly 290,000 employees while training 100,000 of them as AI specialists. Claude Ship addresses the review bottleneck that tends to appear once coding agents spread across organizations of that size.
Claude Ship is available in beta from Monday.
