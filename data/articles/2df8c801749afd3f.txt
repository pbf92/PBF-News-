Anthropic lets Claude create desktop apps for Mac and Windows
Anthropic has released a beta feature allowing Claude users to turn AI-generated artifacts into desktop applications on Mac and Windows. The rollout is available on every plan. Users can click "Install as app" in the Share menu to launch these tools in separate windows with their own icons. The apps offer different permission levels and update automatically when the underlying artifact is edited.
This follows Anthropic's earlier introduction of a feature allowing Claude users to create personalised desktop applications on Mac and Windows.
This lowers the barrier for users to build functional software tools without traditional coding skills.
