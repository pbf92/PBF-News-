Anthropic Debuts "Code Mode" in Claude Code, Letting AI Generate JavaScript to Automate Tasks in Bulk
US-based Anthropic released version 2.1.323 of its developer AI agent Claude Code on November 12, 2026, adding an experimental feature called "Code Mode." The mechanism has the AI generate JavaScript programs on its own to orchestrate multiple development tools and execute a series of tasks together, with expectations for efficiency gains in work involving large volumes of data. Meanwhile, usage conditions and security management practices for corporate adoption are emerging as new points of debate.
Conventional Claude Code used a sequential processing approach in which the AI called tools one at a time—such as executing commands or editing files—read the results, and then decided on the next operation. As the number of work steps grew, round-trip communications with the AI increased, and unnecessary logs returned by searches were loaded into the AI's memory area (context), causing processing delays and higher usage costs.
Code Mode converts this interactive sequential processing into batch execution via programs. When a user instructs the AI in everyday language, Claude writes JavaScript code summarizing the procedure behind the scenes and executes it within the session. It can complete within a single script such operations as running multiple independent commands in parallel and carrying search results from one tool over to the next editing tool. For example, if instructed to rewrite a configuration value, it handles everything at once—from locating the target file's path via search to modifying the code and running tests.
The biggest advantage is the ability to filter data inside JavaScript. The design processes lists of search results and massive logs within the script, extracting and returning only what the AI needs to make decisions—such as "the path of the edited file" or "test results." The chat screen continues to display file edit diffs as before, and the generated JavaScript itself can be audited by pressing "Ctrl+O" to open the history viewer.
At present, the feature is positioned as experimental and is disabled by default. Using it requires the native version of Claude Code v2.1.323 or later, a supported model such as Opus 5.5 or Sonnet 5.5, and an interactive terminal environment. It is not available through the desktop app, the VS Code extension panel, or external clouds such as Amazon Bedrock.
The most important factor for companies to operate it safely is the framework for permission management and security review of AI-generated programs. According to official documentation and other sources, the feature clearly separates the stages of checks depending on the user's permission mode. This is because the timing at which security checks take effect differs significantly between the automatic mode, which leaves decisions to the AI, and the mode in which a human grants approval each time.
Note: Release date and version are based on Anthropic's announcement.
Anthropic has also recently been advancing efforts to integrate documents, presentations, spreadsheets, and whiteboards into a chat-based work environment for paid plans. For spreadsheets, it has demonstrated a feature that generates 12-month forecasts in minutes when business assumptions are entered, and allows users to trace formulas back to the assumptions tab for verification. The company appears to be expanding its product lineup on both fronts: automation for developers and office features for general business users.
The market is focused on how far a design in which AI agents write and execute code themselves can boost productivity at development sites. If round trips for tool orchestration can be reduced, it becomes possible to simultaneously curb token consumption and speed up responses. However, neglecting audits of generated code and permission design carries the risk of unintended file operations and information leaks. Corporate information systems departments will be required to establish internal governance defining the acceptable scope of automatic mode. How much control can be exercised at the experimental stage will likely determine whether full-scale adoption goes forward.
