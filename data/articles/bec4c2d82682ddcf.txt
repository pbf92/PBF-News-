Claude Ship automates code review, fixes, and PR approvals for GitHub repos in beta. It uses three components: Code Review (available), PR Steward and Claude Approvals (beta).
Claude Ship goes beta
Anthropic launched Claude Ship on Monday, a new AI platform designed to automate parts of software development, including reviewing code, resolving conflicts, and approving changes before they are incorporated into production software. Anthropic said Claude Ship combines an existing code-review product with two new AI agents, PR Steward and Claude Approvals, to help engineering teams move software changes from development to deployment more efficiently. Anthropic described the platform’s central objective as eliminating bottlenecks that occur after developers finish writing code but before that code becomes part of a company’s software.
Anthropic said Claude Ship focuses on managing pull requests, with Code Review examining proposed code changes and identifying potential issues before they are merged. Anthropic said Claude Ship is available in beta for customers using Claude Team and Enterprise plans, initially supporting repositories hosted on GitHub.
Agents fix, policies approve
PR Steward is designed to keep pull requests in a merge-ready condition by addressing review feedback, handling merge conflicts, and responding to issues identified by automated tools or human reviewers. Anthropic said PR Steward does not independently approve or merge pull requests, and its role is to prepare changes for the next step. Claude Approvals evaluates pull requests against approval policies established by individual engineering teams, with policies stored in the software repository and able to incorporate code-review findings and other criteria expressed in natural language.
Anthropic said teams can configure Claude Approvals so it can distinguish routine changes that qualify for automated approval from more consequential modifications requiring human review. Anthropic said organizations using Zero Data Retention cannot use Claude Ship, and it also excluded organizations with HIPAA configurations or customer-managed encryption keys.
Enterprise rollout and billing
Anthropic said developers can use a new /ship command in Claude Code to push changes, open pull requests, and initiate automated reviews and fixes. Anthropic said Claude Ship usage is billed based on token consumption, with costs depending on the size and number of pull requests, review complexity, and automated fixes. Anthropic offered eligible Claude Enterprise customers at least $10,000 in promotional Claude Ship credits, which must be claimed by January 15, 2027.
Anthropic said the company’s Claude Code team saw merged pull requests more than doubled between June and September, while the share of reverted changes declined by more than 40%. Anthropic positioned Claude Ship as an expansion beyond AI-assisted code generation toward managing the broader software development process, including the handoffs after code is written.
