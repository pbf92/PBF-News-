Claude Plugin Store Launches with Over 10,000 Plugins as Anthropic Makes Another Play for the Agent-Era Distribution Gateway
On the second anniversary of the MCP protocol's release, Anthropic has merged its two product lines, Connectors and Skills, into a unified Plugins system and simultaneously launched a directory cataloging more than 10,000 plugins. The move consolidates multiple extension entry points previously scattered across the sidebar, settings pages, and conversation menus into a single gateway, open to all tiers — Free, Pro, Max, and Ultra — with Team and Enterprise versions to follow.
Under the official definition, a Connector lets Claude read and write to external software and data, a Skill injects methodologies and operating standards into the model, and a Plugin packages tool connections, skill manuals, along with commands, hooks, and sub-agents into a single one-click-installable unit. The directory includes pure tool connections labeled as Connectors, pure skill packages labeled as Skills, and combination packages containing both, covering high-frequency enterprise applications such as Google Drive, Gmail, Salesforce, Workday, Atlassian, and Shopify.
One notable engineering detail is permission decoupling: when a user removes a plugin, the system does not automatically sever its underlying OAuth or token data connection. The authorization relationship must be managed separately, to avoid a chain reaction of workflow permission failures triggered by mistakenly deleting a plugin.
A Two-Pronged Strategy: Underlying Protocol and Top-Layer Gateway
To judge whether this update will spawn a new industry standard, it helps to lay out the agent-standard timeline of the past two years in a straight line.
As the table shows, the cross-vendor plugin folder specification was finalized by the multi-vendor alliance three months earlier, and Anthropic is not on the first batch of core maintainers for Agent Plugins 1.0.0 — Claude Code has consistently used its own variant of the plugin directory. The focus of this release, therefore, is not on defining yet another underlying folder format.
The real two moves go one down and one up. Downward, Anthropic launched the Skills over MCP public beta during MCP's anniversary week, allowing remote MCP servers to expose tools while directly delivering on-demand SKILL.md workflow manuals; the model only pulls the corresponding skill when it encounters a relevant task. Shopify, HubSpot, and Atlassian have already integrated first. In the same period, two protocol extensions — Tasks for asynchronous long-running jobs and Elicitation for mid-execution safety confirmation — became generally available. This combination means service providers can deliver both tools and business manuals through standard MCP servers, reducing reliance on any single client's local plugin directory, while the underlying protocol's say remains in Anthropic's hands.
Upward, it is using a directory of more than 10,000 plugins to seize the distribution gateway. For most non-developer users, protocol names and configuration files mean nothing; what they need is an app-store-style interface they can search, click to add, and use immediately. Whichever directory is more comprehensive and whichever offers a smoother installation and approval experience is more likely to become the first gateway users encounter when they open their agent every day.
Practical Implications for Developers
In terms of migration cost, the core payloads of each vendor's packaging format are interoperable skills and MCP configurations. Developers need only wrap a minimal manifest file around their core assets to adapt to multiple mainstream clients simultaneously. This means the direction to bet on is relatively clear: keep writing tool interfaces per MCP and business methodologies per Agent Skills — both layers have entered foundation governance and are assets with relatively high cross-platform certainty.
For enterprises providing remote SaaS services, delivering account-specific skill manuals on demand through MCP servers is more aligned with distribution logic than requiring users to manually download local plugin packages, and it can also layer on long-running tasks and secondary confirmation for high-risk operations.
Impact Analysis
For Anthropic, the plugin directory is a key step in extending from model supplier to platform player. With the underlying protocol open-sourced and donated, the mid-layer packaging format interoperable with peers, and the top-layer gateway self-built, this division of labor grows the ecosystem pie while keeping user touchpoints and distribution power in its own hands. For competitors such as OpenAI, Google, and Microsoft, the richness of plugin directories and integration experience will become the front line of agent products in the next phase, and the significance of merely competing on model benchmark scores is declining.
For Chinese developers and SaaS vendors, the practical short-term action is to assess how their own tool and skill assets can be listed across multiple clients at the lowest cost; in the medium term, they need to watch the adoption progress of Skills over MCP — if mainstream SaaS vendors broadly deliver business manuals through MCP servers, the strategic value of local plugin packages will be further diluted.
