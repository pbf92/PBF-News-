TITLE: Anthropic launches Claude Ship to review and approve PRs
OUTLET: TestingCatalog AI News

Anthropic has launched Claude Ship in beta, a system that takes GitHub pull requests through review, fixes, and an approval decision so developers can open a PR and get back to building. It is available on Claude Team and Enterprise plans and combines Code Review, which is already generally available, with two new beta agents called PR Steward and Claude Approvals. Anthropic says the goal is to ship code as fast as teams write it, since many developers now build with agents and a person approving every change struggles to keep up.
Code Review checks pull requests against the codebase through multiple lenses, adversarially verifies and categorizes what it finds, and posts the results to the PR, with Quick, Standard, or Deep review levels for each repository. PR Steward jumps in on failing CI checks, merge conflicts, and review feedback from Code Review, other tools, or teammates, then comments after every push with what it changed and how to undo it.
It is designed not to approve or merge, and developers can steer it by commenting @claude or make it step back with @claude stop. Claude Approvals applies an approval policy the team writes as a file in the repository, working like a smarter CODEOWNERS file. It can approve routine changes on its own or require human sign-off, and it can weigh Code Review results or custom classifiers written in natural language. Anthropic recommends running it in observe-only mode first, before branch protection requires its green light.
Developers can try it on their own changes with the new /ship command, which pushes the change, opens the PR, reviews it, and works through feedback and failing checks. It is rolling out in Claude Code and the desktop app and counts as regular Claude Code usage.
Admins can instead turn it on per repository, picking the review level, when reviews run, and monthly spend limits, while Claude Approvals starts once a policy file lands on the default branch. Usage is billed on tokens, and Claude Ship is not available to organizations with Zero Data Retention, the HIPAA configuration, or customer-managed encryption keys. Eligible Enterprise organizations can claim at least $10,000 in Claude Ship credits by January 15, 2027.
Anthropic built Claude Ship around its own Claude Code team, where Claude writes most of the code. With Claude's review as one layer of a broader process, the team's merged PRs more than doubled from June to September while the share reverted fell by more than 40%. A product manager there can now take customer feedback, talk it through with Claude Tag, have it open a PR, and let Claude Ship carry it to an approval decision.
