Anthropic's Claude Ship lets AI agents review, fix, and approve pull requests on their own
Anthropic launched Claude Ship in beta, a new tool that automatically reviews proposed code changes, fixes problems, and approves merges based on team policies. The system pairs the already available Code Review feature for catching bugs with two new AI agents called PR Steward and Claude Approvals.
Code Review handles the analysis, while PR Steward steps in to rework the draft whenever tests fail, changes conflict, or reviewers leave correction notes, documenting every step along the way. Once that process wraps up, Claude Approvals checks a policy file stored in the project directory to decide whether the AI can approve a routine change on its own or whether a human still needs to sign off.
With GitHub auto-merge enabled and the right policy in place, new code can be merged entirely without human involvement, according to the documentation. The tool is available on the Team and Enterprise plans but billed separately based on token usage. Because PR Steward has no spending cap by default, teams can set their own budgets to keep costs in check. Organizations with specific data privacy requirements can't use the feature.
