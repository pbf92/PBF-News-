Anthropic Releases Beta Feature That Turns Claude Artifacts Into Standalone Mac/Windows Apps
US-based Anthropic has begun beta-testing a feature that lets users install artifacts created with its conversational AI "Claude" as standalone desktop applications. The feature, called "Install as app," is available for the Mac and Windows versions of Claude. The company disclosed the feature by November 24.
Installed apps have their own dedicated icons and launch in their own windows rather than within the Claude interface. Users can share the apps they create with others and choose how much permission to grant them when they run on a computer. The apps also support sending notifications, residing in the menu bar, and app-specific permission settings. Another feature is support for Claude connectors, allowing apps to call integrations with external services.
Anthropic has rolled out a string of updates for developers this week. On November 23, it released a beta of "Claude Ship," which has AI agents handle everything from reviewing GitHub pull requests to revising and approving them. It is available to users on the Teams and Enterprise plans, with two agents—"PR Steward" and "Claude Approvals"—working in conjunction with the existing "Code Review." Developers can submit changes via the "/ship" command in Claude Code.
Note: The release channel feature has been available since November 17.
Claude Ship is priced on a usage basis according to the number of tokens processed and other factors, so bills vary with the volume of pull requests handled. Administrators can set usage caps for Code Review and PR Steward. For the approval feature, Anthropic recommends first trying a monitoring mode that only records decisions, acknowledging that AI may still overlook bugs or vulnerabilities. How much human approval to require is left to each team's design.
For the desktop version, a feature allowing users to choose which channel to receive updates from was also introduced on November 17. The default "stable" channel receives tested versions infrequently, while the "latest" channel lets users get new features and fixes ahead of others at a frequency of about once a day. It is available on all plans and covers the Windows version (excluding installations via the Microsoft Store) and the Mac version. It is not available on the Linux version or on devices where an IT department has set policies.
The series of announcements reflects a competitive axis over how quickly AI-generated code and tools can be moved into actual operations. The app-install feature broadens the scope for even non-engineers to build small tools for their work, while Claude Ship automates the final stages of the development team's workflow. At the same time, mistakes in designing permission management or approval processes could leave companies exposed to the risk of unintended behavior or missed reviews. Corporate IT departments will likely need to establish operational rules, including setting usage caps and making use of monitoring mode.
