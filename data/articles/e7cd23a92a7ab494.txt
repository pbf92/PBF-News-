OpenAI, Cisco Unveil Shirudo to Block Exploits Before Patches
AI-Powered Linux Shields Aim to Protect Vulnerable Systems While Teams Develop Fixes
The growing number of vulnerabilities found by artificial intelligence models has given organizations a shorter timeframe to send out patches, even if they use agents to help plug any holes.

OpenAI and Cisco released Shirudo, an open-source approach that creates "shields" to block exploits while security teams roll out their longer-term patches, in a bid to widen that timeframe further. Shirudo, Japanese for "shield," runs on Linux systems.
AI models, particularly the more cyber-capable ones such as OpenAI's GPT-6 Astra or Anthropic's Mythos 5, have surfaced previously unknown vulnerabilities. Already overwhelmed security teams are being encouraged to turn to AI agents to find and patch these issues. Even so, testing and deploying patches still takes days or weeks.
"We're giving defenders better models and tools to find and fix vulnerabilities faster, but finding a bug today doesn't mean you can patch every system tomorrow," Greg Brockman, president and co-founder of OpenAI, said in a blog post. "We are partnering closely with Cisco on Shirudo to help teams protect the systems they need to keep running while they build and roll out a fix. So many teams rely on the same software that it makes sense to build these tools in the open."
OpenAI and Cisco invited other developers, security researchers and infrastructure operators to iterate and contribute to their work on Shirudo.
With Shirudo, security teams can test temporary safeguards "to block the behavior that exposes a vulnerability while allowing legitimate requests through." If the test works, the shield can be deployed without bringing the entire system down.
The agent writes a temporary block that sits in front of the vulnerable code and prevents the kind of malicious input the exploit depends on. The shield lets security teams test if the patch works while stopping anyone from accessing it. On Linux, the operating system that Shirudo currently works with, many of those shields run inside the operating system's core using a technology called extended Berkeley Packet Filter, or eBPF.
The agent decides where to intercept the attack and where to place the shield it wrote to block it. The agent generates the patch code and begins testing it while the shield blocks malicious attempts to access the kernel.
OpenAI said it tested Shirudo on the Java4Shell vulnerability. Its team used Codex agents, the same agent platform that helped the research firm Calif find Java4Shell. The lab pointed the agent to do a search on the Elasticsearch platform, which allows users to look data within their system and happens to run on the Java language. The team, using Shirudo, added a shield that will check any input they make to Elasticsearch. When the team attempted to exploit the Java4Shell vulnerability by writing malicious input into Elasticsearch, the shield blocked that attack while the platform kept running.
"When attempting to exploit the vulnerability, the shield rejected the malicious input, blocking the attack while Elasticsearch continued running," OpenAI said.
Shirudo is an open-source platform licensed under the BSD 2-Clause. Cisco and OpenAI said the goal is to make "tested shields available alongside vulnerability disclosures" while the open-source community builds out patches.
AI has been both a boon and bane for security teams. It has surfaced more new vulnerabilities and enabled new attack patterns. But OpenAI and Cisco said platforms like Shirudo, powered by AI, are the first step toward building infrastructure that adapt just as quickly to these emerging threats.
"We want to strengthen the operating system foundations needed to deploy these protections at scale, including hardening the kernel and core services, limiting workload permissions, and making updates and recovery safer," OpenAI said.
