TITLE: Flight name
OUTLET: PPC Land

Flight name is a dimension in Amazon Ads unified reporting that holds the text label of a flight: a period inside a programmatic campaign that carries its own start date, end date and budget. It exists because people do not read identifiers. A report row keyed to a string beginning "flg_" tells a planner nothing, while a row labelled "Q4 holiday push - December" can be checked against a media plan at a glance. The field is the human side of a pair. Flight ID is the fixed key a system joins on; Flight name is the column a buyer, an account manager or a client actually reads.
The field is one of five flight attributes in the unified reporting dimensions reference that Amazon updated on November 11, 2026. The other four are Flight ID, Flight start date, Flight end date and Flight budget. PPC Land's field-by-field reading of the reference places all five in the "Level of detail" category, and none lists a former name. That sets the flight apart from the levels around it. Campaign name was "Order" in old DSP reports, according to the same reference, because the programmatic order became a campaign. The flight kept both its name and its place.
Where the label sits
Amazon's programmatic product was called Amazon DSP until September 29, 2026, when Amazon renamed it DVA. Its structure has four levels in current vocabulary. An advertiser account holds campaigns, campaigns hold ad groups (the former line items), and ad groups hold ads.
Flights hang off the campaign. A campaign has an overall date range and budget; its flights divide that range into dated segments, each paced against its own amount. Teikametrics, an Amazon ads software company, described flights in its June 2025 help documentation as "specific time segments or intervals within an advertising campaign", each with "its own budget, start and end dates". Because ad groups draw on whichever flight is live, a flight label applies to every ad group row beneath it during that period. In a report, adding Flight name splits each campaign's rows by period.
How a flight gets its name
The label is set when the flight is created or edited, in the Ads Console, through bulk tools or through the Amazon Ads API. In the version 1 DSP API, flights are a sub-resource of a campaign. According to API documentation republished by the integration company One, last updated February 25, 2026, a POST request to /dsp/v1/campaigns/{campaignId}/flights takes an array of flight objects. Three fields are required in each: budgetAmount (a number with a minimum of 1, in the currency set at advertiser level), startDateTime and endDateTime (both RFC 3339 timestamps). The name field is optional, alongside an optional impressionBudgetAmount for campaigns bought on impressions.
That optional status matters for reporting. A flight can exist, spend money and appear in a report without any label its owner chose. What Amazon writes into the Flight name column in that case, whether a blank, a system default or a generated string, is not stated in the documentation reviewed for this article.
The API returns a flightId for each new flight, and new flights are "appended to the campaign's existing list of flights", the documentation states. A separate update endpoint changes existing flights, and a delete endpoint removes them by ID. Since a name can be changed after creation while the ID cannot, a report pulled before a rename and one pulled after it will show different labels for the same period. Only Flight ID connects the two.
Naming in practice
Amazon does not publish a mandatory format for flight names, and no length limit, character set or uniqueness rule was found in public documentation as of November 2026. Two flights in the same campaign can, on the evidence available, carry the same label.
Agencies and software vendors fill the gap with their own conventions. Perpetua, an Amazon ads software company, publishes help documentation on naming conventions for the DSP campaigns it manages, and agencies commonly encode month, quarter, promotional event or funnel stage into the label. A typical pattern might read "2026-12 | Holiday | Upper funnel". A label that carries period and purpose lets a pivot table group flights without a lookup against the plan.
A worked example shows the use. A kitchenware brand runs a DVA+ campaign from October 1 to December 31, 2026, with a total budget of $90,000 split into three flights: $20,000 named "Oct - always on", $25,000 named "Nov - Black Friday" and $45,000 named "Dec - holiday". A unified report with Campaign name, Flight name, Flight budget and spend as columns produces three readable rows. If the November flight spent $21,000 of its $25,000, the shortfall is visible against a label that says what the money was for. If someone later renames that flight "Nov - BFCM", the Flight ID column is what keeps historical rows tied together.
Labels are often produced by hand. Intentwise, another Amazon ads software vendor, wrote in November 2025 that many advertisers set flights monthly and recreate them manually each period, which means a fresh name each time unless a tool copies it forward.
Origin and evolution
The flight predates the field by decades. In media planning, a flight is the period during which a campaign runs, and flighting is the practice of concentrating spend into bursts separated by gaps, as set out in PPC Land's explainer on flights. Programmatic platforms carried the concept into software as a dated budget segment on an order or insertion order, and labelled it as they did every other object.
Amazon's programmatic platform launched as Amazon Advertising Platform and was renamed Amazon DSP in September 2018. Its orders carried flights from early on, though Amazon has not published a launch date for the feature. Funnel, a marketing data company, already listed flight fields in its Amazon DSP budget dataset, refreshed every four hours.
Amazon's DSP campaign and creative management APIs reached general availability on January 9, 2025, after a beta announced in October 2024, exposing flights and their optional names in code. Unified reporting then moved the field into a schema shared with sponsored ads. Amazon launched the reporting system in beta on November 11, 2025, took it to general availability on June 8, 2026, and published the 156-dimension reference in November 2026.
Why it matters
For buyers and agencies, Flight name is how flight-level performance is communicated. Pacing reviews and client reports discuss named periods, and the label is what appears on the slide.
For data teams, the field matters because of the migration deadline. Amazon's November 2026 timeline makes legacy reports read-only on December 17, 2026, and deletes unmigrated reports and their history on January 31, 2027. Dashboards that grouped legacy DSP exports by flight label need the unified column mapped before then.
The field also reflects how much manual structure remains. In the DVA+ campaign builder, budget flighting sits among the advanced settings rather than the default tier. Campaigns built on defaults may carry a single flight spanning their whole run, which leaves Flight name with little to distinguish.
Limitations and disputes
The field applies only where flights exist. Sponsored Products, Sponsored Brands and Sponsored Display are not built from flights; they use daily or campaign-level budgets. Amazon's documentation says a dimension that does not fit an ad product "appears as null", so in a mixed report most sponsored ads rows show an empty Flight name.
A name is also unreliable as a key. It is optional, editable and, as far as public documentation shows, not required to be unique. Analysts who group by Flight name alone risk merging two periods that share a label or splitting one period that was renamed mid-campaign.
The public record is thin. Amazon's own help pages on flight settings, including any limits on name length or format, were not available to this review. The API details above come from a republished copy rather than Amazon's developer portal, and vendor descriptions of flights do not always agree. Teikametrics, for instance, has described flights as carrying their own targeting, while the version 1 API places targeting on ad groups and gives flights only dates and budgets.
Flight name versus adjacent terms
Flight ID is the system identifier for the same period. It is fixed at creation; the name can change. Campaign name labels the container one level up and was "Order" in legacy DSP reporting; one campaign can hold many named flights. Ad group name labels the unit that holds targeting and bids, one level below the campaign and running across flights rather than inside one. Budget segments in Google's Display & Video 360 (DV360) serve a similar purpose on insertion orders, each with its own description field, though Google uses the term "flight" in separate pacing settings, one of which, Flight ASAP, was removed in November 2024.
Recent developments
The November 2026 reference update put Flight name in the same table as sponsored ads fields for the first time, with null values for products that lack flights. Amazon's move of agency fees to account, campaign or ad group level after January 31, 2027 does not extend to flights.
The direction of Amazon's tooling points to fewer manual levers. DVA+, the AI-led campaign type that combines DSP, Sponsored Display and Sponsored TV buying, entered US closed beta in autumn 2026, with general availability planned in 35 markets in the first quarter of 2027, according to Amazon. As of November 2026, DVA+ budget pacing can be daily, weekly, monthly or lifetime. How Flight name will be populated for campaigns that rely on those pacing modes rather than explicit, hand-named flights has not been documented.
