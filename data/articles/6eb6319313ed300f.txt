TITLE: Claude Code vs Codex: $8/$40 vs $2/$10 per Million Tokens
OUTLET: shattered.io

Claude Code now runs Claude Fable 5.2 at $8 per million input tokens and $40 per million output tokens, while OpenAI’s Codex CLI can switch between GPT-6.2 Sol at $2/$10 and GPT-6.2 Astra at $8/$40. Google’s answer is the messiest of the three. Gemini CLI still exists, but Google steered individual users to Antigravity CLI back in May. Anyone typing “claude code vs codex” into a search box this week is really choosing between those three situations.
The price gaps are big enough to matter, and the product histories are tangled enough that old comparisons now mislead. A head-to-head built around Gemini 2.5 Pro or GPT-5.4 describes tools that have moved on. For a narrower pairing, there is a separate look at Gemini CLI against Claude Code. The sections below set all three terminal agents side by side, with current models, current prices and a plain account of what each vendor has and has not published.
One caution before the tables. No independent lab has published a verified head-to-head of the three agents on the same tasks. Every performance number below comes from the vendor that sells the product. Where the numbers run out, the analysis says so rather than filling the gap.
Claude Code vs Codex CLI vs Gemini CLI at a Glance
Start with the shape of each product, because the labels hide real differences. Claude Code is Anthropic’s agentic coding tool, and Anthropic still calls it Claude Code as of November 26, 2026. Codex CLI is the terminal piece of OpenAI’s Codex, which also covers Codex Cloud, an IDE extension and desktop clients. Gemini CLI is Google’s open-source terminal agent under the Apache 2.0 license, now in a managed handoff toward Antigravity CLI.
The newest models line up like this. Anthropic announced Claude Fable 5.2 and Claude Mythos 5.2 on November 9, 2026, and Fable 5.2 works inside Claude Code. OpenAI made GPT-6.2 Astra and GPT-6.2 Sol available in Codex on November 17, 2026. Google released Gemini 4 Neon on November 18, 2026, six days after Gemini 4 Hydrogen. Those three launches landed within ten days of each other, which is why anything older than mid-November is already stale.
The takeaway from the grid: the first two are direct rivals with matching entry prices, while the third is a different kind of decision. Choosing Google today means choosing between a legacy open-source CLI that enterprise and API-key users can still run, and a newer Go-based terminal tool that belongs to Google’s wider Antigravity platform.

Claude Code in November 2026: Fable 5.2, Fast Mode and Plans
Anthropic’s November 9 announcement is the event that reset this comparison. It introduced Claude Fable 5.2 and Claude Mythos 5.2 as the company’s most capable models for technical work, and it superseded the 5.1 versions of both. Anthropic describes Fable 5.2 as setting a new bar in coding, finance and the sciences. The company also claims output speeds up to 30% faster than the 5.1 releases, along with lower token prices. Those are Anthropic’s own figures and no outside lab has replicated them.
Pricing for the new model sits at $8 per million input tokens and $40 per million output tokens. That is cheaper than the prior generation, since Fable 5.1 was reportedly listed at $10 and $50 earlier in November. Fast mode costs double: $16 per million input and $80 per million output, in return for up to 2.5 times faster token generation. Anthropic says fast mode is available inside Claude Code, where it is labeled a research preview.
The 5.5 family underneath Fable
Fable is not the only choice inside the tool. Anthropic’s September and October releases built out a 5.5 family: Claude Opus 5.5 on September 22, Claude Sonnet 5.5 on September 28 and Claude Haiku 5.5 on October 7, according to the company’s model listings. Anthropic says Opus 5.5 leads in agentic coding and knowledge work while costing 40% less to run than Opus 5 on typical workloads. It also says Sonnet 5.5 runs more than 30% faster than Sonnet 5 and costs up to 30% less for most work.
For daily use, that spread matters more than the flagship price. A developer can hand routine edits to a cheaper tier and keep Fable for the hard problems. Anthropic’s pricing page puts Opus 5.5 fast mode at $8/$40 per million tokens and states that fast mode costs twice standard pricing, which implies a standard Opus 5.5 rate of $4/$20. Newcomers can follow a step-by-step Claude Code tutorial to get a first project running before worrying about tiers.
Plans, limits and the Anthropic backdrop
The entry plan is Pro at $20 a month when billed monthly, or $200 up front with the annual discount. Anthropic’s pricing page says Fable is included for up to 50% of weekly usage limits on Pro plans and standard Team seats, though nothing retrieved confirms those limits are unchanged today. Team seats appear at $25 per seat when billed monthly, with a premium seat tier priced higher. The page also advertises pooled API credits of up to $500 a month for team admins.
On the corporate side, Anthropic announced on November 20, 2026 that it had completed its initial public offering, so the company behind Claude Code is now publicly listed. A single source reports a price of $83 per share. For buyers, the practical effect is a vendor with more public disclosure obligations and, presumably, more pressure to show that coding revenue holds up. Anthropic also claims Claude Code holds more than half of the AI coding market, but that is the company’s own assertion and the sources do not confirm it independently.
Finally, a note on newer agent features. Claude Code introduced dynamic workflows on May 28, 2026 as a research preview for very large-scale tasks, and agent teams on February 5, 2026, which let multiple agents work together. Developers weighing the editor side of the market can also compare Cursor against Claude Code.
Codex CLI: GPT-6.2 Sol, Astra and the Version Floor
OpenAI sells Codex as a family: the CLI, an IDE extension, Codex Cloud for delegated tasks, desktop clients and GitHub-based code review. The terminal piece is the one this comparison covers. On November 17, 2026, OpenAI made GPT-6.2 Astra and GPT-6.2 Sol available in Codex and ChatGPT Work for Plus, Pro, Enterprise and Edu users, and later notes extend them to Business workspaces. Using either model requires Codex CLI 0.166.0 or later, per OpenAI’s help center.
The two models are priced far apart. OpenAI lists GPT-6.2 Sol at $2 per million input tokens, $0.10 per million cached input tokens and $10 per million output tokens. GPT-6.2 Astra costs $8, $0.40 and $40 at standard speed. That makes Astra four times as expensive as Sol on every line of the rate card. OpenAI has not published a head-to-head that explains when the extra spend pays off, so the sensible default is to start on Sol and escalate only for tasks that stall.
What changed in the last three months
The sequence runs in order. GPT-5.4 and GPT-5.4 mini became unavailable in Codex for ChatGPT-account sign-ins. GPT-6.1 Terra began rolling out in Codex on October 26. The Astra and Sol pair arrived on November 17. Along the way, OpenAI renamed “priority processing” to Fast mode, and Codex CLI 0.154.0 added experimental support for starting or forking tasks in separate Git worktrees. That last feature matters for anyone running parallel agents on one repository.
A community post dated November 1 describes a major Codex CLI refresh with a new terminal interface, full chat-history access and better copy-paste behavior. A recap of OpenAI’s DevDay also credits the CLI with voice control, though only one source says so. Anyone starting from zero can follow a Codex CLI setup walkthrough, and a usage-survey comparison of Codex and Claude Code covers adoption data from developers.
Gemini CLI and Antigravity CLI: What Google Changed
This is the section that most older comparisons get wrong. On May 19, 2026, Google announced that Gemini CLI would transition to Antigravity CLI, which it describes as a Go-based, faster terminal tool that handles asynchronous work and shares one agent harness with the new Antigravity 2.0 desktop application. Google’s pitch is multi-agent workflows. The company said individual and free users had to move before June 18, 2026, when Gemini CLI and the Gemini Code Assist IDE extensions stopped serving requests for Google AI Pro, Google AI Ultra and free Code Assist for individuals.
Enterprise customers kept access. Organizations on Gemini Code Assist Standard and Enterprise licenses retained Gemini CLI, and paid Gemini API keys still work with it. The open-source repository keeps shipping. Release records show v0.68.0 on November 10, a v0.71.0 preview on November 19 and nightly builds through November 23. One source reports the v0.71.0 stable release on November 24. Project docs describe weekly stable promotions every Tuesday at 2000 UTC.
Gemini 4 Neon and Hydrogen
Google’s model news is stronger than its CLI news. Gemini 4 Neon, dated November 18, 2026, is priced at $3 per million input tokens, $0.15 per million cached input tokens (a 95% discount) and $15 per million output tokens, with a 1 million token context window. Gemini 4 Hydrogen, released November 12 for agentic workflows, costs $1.50 and $7.50 with the same context size. Google’s own page claims best-in-class results for Neon on Terminal-Bench Science (70.5%), RiemannBench (84.0%) and HLE-Diamond (71.3%).
On the plan side, Google introduced a Google AI Ultra tier at $100 a month on May 19, 2026, with five times the Antigravity usage limit of Google AI Pro. No current Gemini CLI or Antigravity CLI price table turned up in the sources, so the sections below treat Google’s tool as priced through model tokens and subscription tiers rather than as a standalone product with a fee. Google also published a November 3 study on routing coding tasks across Gemini models and thinking levels to cut cost per task.

Subscription plans
OpenAI also gives a budgeting anchor that Anthropic and Google do not. Its help center estimates Codex usage at roughly $100 to $200 per developer per month, while warning that the real figure depends on model choice, concurrency, automations and Fast mode. That range is wide, but it is an official number from the vendor, and it sets a floor for anyone planning a team rollout. A single source reports that Business workspaces created from November 23 to 30 get double weekly usage through December 31.
