TITLE: Campaign country
OUTLET: PPC Land

Campaign country is a dimension in Amazon Ads unified reporting that labels each row with the country a campaign was built for. Amazon defines it as "The country in which the campaign is delivering." It exists because an Amazon advertiser can now run the same brand, and often the same campaign, in several national stores at once, and a report that mixes Amazon.de, Amazon.co.jp and Amazon.com rows without a country label is close to useless. Unlike the delivery-based geography fields, Campaign country does not describe where a shopper or viewer was. It describes where the campaign was pointed. For Sponsored Products, Sponsored Brands and Sponsored Display, it is the only location attribute in the report, as PPC Land noted in its review of all 156 unified report dimensions.
What the field records
A unified report is assembled from dimensions, which describe what is being counted, and metrics, which count it. Campaign country belongs to the campaign group of dimensions, alongside Campaign ID, Campaign name, Campaign currency code, Campaign budget amount and Campaign start and end dates, all properties set by the advertiser rather than observations taken when an ad is served.
That distinction shapes how the field behaves. Every row belonging to a given campaign carries the same Campaign country value. Add the dimension to a report of 40 Sponsored Products campaigns across five European stores and the rows sort into five buckets, one per country, with impressions, clicks, spend and attributed sales summed inside each. A shopper in Austria who buys from Amazon.de is still counted under Germany, because the campaign was set up for the German store.
The sibling field Country, by contrast, is recorded per impression from the device's observed location and, according to the dimension reference Amazon updated on November 11, 2026, carries markers only for DVA+ and Sponsored TV. Where a dimension does not fit an ad product, Amazon's documentation says its value "appears as null", which it describes as expected behaviour that lets different ad products share a single report. A mixed report therefore shows a blank Country column on sponsored ads rows, with Campaign country as the only geographic handle available for them.
How the value is set
For the sponsored ads products, country is inherited from the marketplace. Sponsored Products, Sponsored Brands and Sponsored Display campaigns run inside a single Amazon store, and in the Amazon Ads API each store-level advertiser is represented by a profile, which carries a country code, a currency code and a time zone. A campaign created under the profile for Amazon.fr is a French campaign from the moment it exists. Its budget is in euros and its ads appear only to shoppers browsing that store.
Amazon's country codes do not always follow ISO 3166-1, the international standard for two-letter country codes. Ads API profiles use "UK" for the United Kingdom, where the ISO code is "GB". Data teams joining Amazon exports to tables keyed on ISO codes have to map that exception by hand.
Cross-border building tools do not change the one-campaign-one-country rule underneath. On October 26, 2021, Amazon let sellers and vendors in the United States, Canada and Mexico create Sponsored Products auto-targeted campaigns for several countries in one workflow. According to Amazon's launch notice for cross-country campaign creation, the campaign is duplicated in each target country, with budgets, bids and products localised for each. The result is several campaigns, each with its own Campaign ID and its own Campaign country, joined by a Global Campaign ID where Amazon's multi-country structure applies.
For programmatic campaigns, country became an explicit choice in 2026. On July 30, 2026, Amazon moved DSP advertisers to a single global account across 34 countries. Before that, a DSP advertiser existed in one regional account, so the country was implied by where the advertiser had been created. Afterwards, the country is selected when the campaign is created, and the DSP campaigns endpoint accepts an optional country code that defaults to the account's original country when left out.
A worked example
Consider a kitchenware brand selling in Germany, France, Italy and the United Kingdom. It runs Sponsored Products in all four stores, Sponsored Brands in Germany only, and a DVA+ streaming campaign aimed at the United Kingdom.
A unified report grouped by Campaign country produces four rows. The German row combines Sponsored Products and Sponsored Brands. The United Kingdom row combines Sponsored Products and the DVA+ campaign. Adding Country splits only the DVA+ portion further: if a few thousand streaming impressions reached devices located in Ireland, the DVA+ rows divide into United Kingdom and Ireland under Country, while Campaign country still reads United Kingdom for all of them. The sponsored ads rows show null under Country.
Currency adds a further layer. The German, French and Italian rows report spend in euros, the United Kingdom rows in sterling. Campaign currency code identifies which currency each row uses, and Amazon's report-level currency conversion is needed before the four rows can be summed into one total.
Origin and evolution
Country has been built into Amazon's sponsored ads model since Sponsored Products launched, because each campaign belonged to one store. The difficulty was never recording the country but seeing several countries together.
Amazon closed that gap in stages. The 2021 cross-country builder handled creation. On September 21, 2023, Amazon introduced a multi-country campaign manager for sponsored ads, with a currency visualisation option to convert campaign metrics into one currency. On September 28, 2023, its global ads launch allowed a single sponsored ads report across countries, letting marketers select a currency of their choice for converted metrics. Once rows from several countries could appear in the same file, a country label on every row became necessary.
Programmatic buying followed a different path. Amazon DSP let self-service advertisers choose a reporting and billing currency from May 2024, a change PPC Land covered as Amazon DSP enabling advertiser currency selection. The global account arrived in July 2026.
Reporting was merged in parallel. Amazon opened unified reporting in beta on November 11, 2025 at its unBoxed conference and moved it to general availability on June 8, 2026. The November 11, 2026 dimension reference fixed the campaign-level vocabulary, mapping the former DSP order to campaign and line item to ad group, and published the Campaign country definition quoted above.
Why it matters
Campaign country is the field that lets a multinational Amazon account be read by market. Country managers, regional finance teams and agencies with national mandates need spend and sales split by store, and for sponsored ads it is the only way to do so inside the unified report.
It also matters for the migration under way. Amazon has set December 17, 2026 as the date on which creation and editing of legacy reports stop, and January 31, 2027 for the deletion of unmigrated reports and their history, as PPC Land reported when it warned that advertisers will lose unmigrated reports. Many legacy sponsored ads exports were pulled per profile, so the country was implicit in which file a row came from. Once those feeds move into a single unified report, the country has to be carried as a column, and Campaign country is that column.
Limitations and disputes
The central limitation is that Campaign country measures intent, not delivery. For sponsored ads, the gap is small because ads appear inside one store, but the store is not the shopper: a Belgian customer buying from Amazon.fr is reported under France. For DVA+ campaigns that reach the open internet and connected TV apps, the gap can be larger, which is why Amazon keeps a separate, impression-level Country dimension for them.
Third-party measurement can make the distinction contentious. In an August 2022 Adobe community thread, an advertiser reported that Amazon DSP placed 99 per cent of impressions in Belgium while Adobe Analytics and Campaign Manager showed mostly out-of-country traffic. One respondent suggested "Amazon is probably reporting intended targeting." The cause was never established publicly, but the episode illustrates how a campaign-level country can be mistaken for a delivery figure.
The documentation itself is uneven. PPC Land's tables count no geography fields for the sponsored ads products, while the same reference says Campaign country applies to them, because Amazon files the field under campaign attributes rather than geography. Amazon has not published, in material reachable as of November 2026, how Campaign country is populated for a DVA+ campaign created before the July 2026 global account, or whether it reflects the account's original country in those cases.
Commonly confused terms
Country. The nation where each impression was delivered, recorded from device location and applying to DVA+ and Sponsored TV. Campaign country is the setting; Country is the result.
Country code. The code version of the delivery country, used for joins. It shares Country's product scope and is not a code for Campaign country.
Audience segment country code. The country in which an audience segment is defined, which can differ from both the campaign's country and the delivery country.
Marketplace. The Amazon store, such as Amazon.co.jp. For sponsored ads the campaign's marketplace and Campaign country coincide, but Advertised product marketplace and Converted product marketplace describe where products are listed and bought, which can differ.
Recent developments
The November 11, 2026 dimension reference is the current authority on the field, and PPC Land's reading of it was published the following day. DVA+ remains in closed beta in the United States, with general availability in 35 markets targeted for Q1 2027, which will put Campaign country on programmatic rows in many more stores. Legacy report creation ends on December 17, 2026, leaving the unified report, and Campaign country within it, as the standard way to split Amazon advertising by national market.
