TITLE: Anthropic's new Claude Ship service hands the reins to agents to fix and review code changes – but the company warns it may 'miss bugs, security vulnerabilities, or other issues'
OUTLET: IT Pro

Anthropic has unveiled Claude Ship, claiming the new service will allow agents to review pull requests, fix code problems, and even approve changes.
According to the company, the goal of the new service is to help "ship code as fast as teams write it," while still keeping control of policies.
The rise of AI-powered coding has caused issues for developers in recent years, with half saying they don't bother to check AI generated code because it takes longer than reviewing code written by their colleagues.
In a bid to address that, Claude Ship can review pull requests, fix any issues, and then decide using policies whether to merge the change.
"Most teams want a person to approve every change, and that's easy to keep up with when people write every line," the company said in a blog post. "But a lot of developers build with agents now. On the Claude Code team, Claude writes most of our code, and we wanted everything after the PR to move that fast too."
"Teams stay in control of where it runs and which changes need a person," the company added.
Anthropic said that the new features have been supporting teams internally at the company, with developers reporting promising gains.

"On the Claude Code team, where Claude's review is one layer of a broader process, merged PRs more than doubled from June to September while the share reverted fell by more than 40%," the company said.
Claude Ship is currently available in beta and available now on Claude Team and Enterprise plans for repositories on GitHub.
How Claude Ship works
According to Anthropic, Claude Ship is a combination of its existing Code Review product, as well as two beta agents, PR Steward and Claud Approvals.
Those tools manage code through a process of looking for issues, sorting fixes, looking for further issues, fixing those, and then finally pushing the code through to approval.
Claude Approvals will consider team policies before approving routine changes, with any more challenging or risky changes sent to a human to look over first.
"Code Review performs an in-depth review of pull requests against the codebase through multiple lenses," the company noted. "It collects findings, adversarially verifies them, categorizes them, and posts them to a PR."
The PR Steward tool doesn't approve or merge pull requests, but looks at conflicts and problems, reviewing feedback from Code Review or even team members, who can tell it to stop or send it instructions.
"After every push, it comments with what it changed and how to undo it," Anthropic explained.
Thereafter, Claude Approvals takes over, using a policy that the human coding team has created as a file in the repository.
"Claude can approve routine changes on its own if the policy allows it, or can require deeper human sign-off for certain scenarios," the company said.
Anthropic advised that users start slow rather than leaping into automated code approvals. Indeed, the company said the tool “may miss bugs, security vulnerabilities, or other issues."
"For most customers, we recommend enabling this first in observe-only mode to build confidence before configuring branch protection to require Claude Approvals' green light," the blog post said.
