TITLE: Google mandates new security standards for AI agents
OUTLET: SC Media

As detailed in Infosecurity Magazine, Google is implementing new security requirements for AI agents operating within its Workspace and cloud environments to address evolving digital threats.
Starting in February 2027, all users must connect AI agents through dedicated Model Context Protocol servers or a new command-line interface. These tools replace traditional Representational State Transfer application programmable interfaces, which Google officials argue are insufficient for autonomous, machine-speed operations. The new systems incorporate native data loss prevention checks, human-in-the-loop confirmations for sensitive actions and strict OAuth client validation. Additionally, the company launched the Google Cloud Agent Gateway to provide an extra layer of security. This gateway verifies agent identities against a central registry, enforces identity and access management policies and utilizes Model Armor to screen for prompt injection and data leaks. By moving away from legacy connection methods, Google aims to mitigate risks associated with unauthorized access and adversarial attacks. These changes reflect a broader industry shift toward embedding security directly into the infrastructure used by autonomous agents, ensuring that valid access tokens alone are no longer the sole gatekeeper for sensitive enterprise data across documents, emails and cloud infrastructure.
