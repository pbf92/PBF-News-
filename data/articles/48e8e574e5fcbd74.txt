TITLE: OpenAI adds over 2,000 internet addresses ChatGPT uses to visit websites
OUTLET: PPC Land

OpenAI today expanded the published list of internet addresses that ChatGPT uses when it opens a web page for one of its users, adding more than 2,000 addresses without a public announcement. The change surfaced through a monitoring tool run by the search consultancy Merj, whose alert counted 2,064 new addresses in 129 blocks of 16. A PPC Land comparison of the file against an earlier copy counts 130 new blocks, or 2,080 addresses, and no removals.
In Short
OpenAI added more than 2,000 internet addresses today to the public list that identifies ChatGPT when it visits a web page on someone's behalf. Website owners, publishers and security services use that list to tell genuine ChatGPT visits from impostors that only borrow its name. Until a site's own copy of the list is refreshed, visits from the new addresses can look unverified, and OpenAI has not said why it needs them.
What changed in the list
The list in question is a small file, chatgpt-user.json, that OpenAI publishes at openai.com. It names every block of internet addresses from which ChatGPT-User, the agent that fetches pages during conversations, may connect. An internet address, or IP address, is the number a computer uses to send and receive traffic. The file groups those numbers into blocks written in a shorthand: an address followed by a slash and a number. The smaller the number after the slash, the bigger the block. A "/28" block holds 16 consecutive addresses. A "/16" block holds 65,536.
The version of the file dated today carries a creation time of 07:18:51 on November 25, 2026, without a time zone. It holds 367 entries: 366 blocks of 16 addresses and one large block, 9.129.0.0/16. Together they cover 71,392 addresses, according to a PPC Land calculation.
A public mirror of OpenAI's crawler lists on GitHub, maintained by developer Fabrizio Cafolla, still held the earlier version when PPC Land read it at 17:57 UTC today. That copy has 237 entries. Every one of them is still in today's file. The 130 entries that are new are all blocks of 16.
All figures in the table are PPC Land calculations from the two versions of the file.
The table explains why one change can look both large and small. The single /16 block accounts for about 92% of every address on the list, PPC Land calculates. Measured against the whole list, today's additions raise the total by 3%. Measured against the blocks of 16, which are the units the list has been growing in, the count rises by more than half in one update.
Merj's count and PPC Land's count differ by one block. Merj's alert, which carries a timestamp of 01:49 "Today", lists the added blocks in text order; the first 57 visible entries match PPC Land's list exactly. Today's file was generated at 07:18:51, which may be later in the day. A block added between the two moments would account for the gap, but neither OpenAI's file nor the alert records when individual blocks appeared, so the difference cannot be settled from the published material.
Where the new blocks sit
The new addresses are scattered, not clustered. Of the 130 blocks, 49 begin with the number 20, the most common starting number on the list both before and after the change. The rest spread across 14 other starting numbers, from 4 to 172. They fall into 76 different /16 neighbourhoods; 64 of the blocks land in neighbourhoods that already held ChatGPT-User addresses, while only five share a narrower /24 range, a run of 256 addresses, with an existing entry.
Most of the new blocks stand alone. 104 are isolated blocks of 16. The other 26 sit side by side with at least one other new block, forming 11 continuous runs.
The file itself says nothing about where in the world these addresses are, who operates the networks they belong to or which part of ChatGPT will use them.
What ChatGPT-User does
OpenAI runs several automated visitors, and each has a separate name and a separate job. According to OpenAI's crawler documentation, ChatGPT-User handles certain actions that people take in ChatGPT and in Custom GPTs. When someone asks ChatGPT or a Custom GPT a question, it may visit a web page under the ChatGPT-User name. The same agent is used when people work with outside applications through GPT Actions.
OpenAI's documentation draws a firm line between this agent and its crawlers. ChatGPT-User, it says, does not crawl the web automatically. It is not used to decide whether content appears in ChatGPT search; OpenAI points site owners to OAI-SearchBot for search opt-outs and automatic crawling. Training data is a third job, handled by GPTBot. Since April, a fourth agent has checked advertising landing pages: OpenAI's OAI-AdsBot visits pages submitted as ads on ChatGPT, and its documentation references no published address list at all.
The distinction matters because of robots.txt, the plain text file in which sites tell automated visitors where they may go. According to OpenAI, because a user starts these actions, robots.txt rules may not apply to ChatGPT-User. That wording arrived on December 9, 2025, when OpenAI removed the robots.txt compliance language for ChatGPT-User from its crawler documentation. The earlier text had applied robots.txt tags to all three of its agents at the time.
The practical effect has been measured. TollBit's State of the Bots report for the first half of 2026 found that ChatGPT-User, Bytespider and Youbot each reached disallowed pages on nearly half of the European sites that named them in robots.txt. For a site that wants to treat ChatGPT-User differently from other traffic, the address list is therefore one of the few remaining handles: robots.txt may be set aside, but a request's origin can still be checked.
How the published list works
OpenAI's documentation and the file itself describe the system in a handful of parts. The documentation contains no separate verification procedure and no update schedule.
- The name. Requests carry a user agent string, the label a visitor sends with each request: Mozilla/5.0 AppleWebKit/537.36 (KHTML, like Gecko); compatible; ChatGPT-User/1.0; +https://openai.com/bot.
- The purpose. According to OpenAI, the agent visits pages when users ask ChatGPT or a Custom GPT a question, and for GPT Actions. It is not an automatic crawler.
- The robots.txt position. According to OpenAI, robots.txt rules may not apply, because a user initiates the action.
- The address file. The documentation lists published IP addresses at https://openai.com/chatgpt-user.json.
- The format. The file has two fields: "creationTime", a timestamp with no time zone, and "prefixes", a list in which each entry carries one "ipv4Prefix" value. Today's version contains 367 entries and no IPv6 addresses.
- The check. A request that carries the ChatGPT-User label but arrives from an address outside every listed block does not match the published list. Services that classify verified bots confirm a claimed operator through DNS records, published address ranges or a cryptographic signature; for ChatGPT-User, OpenAI publishes the address ranges.
- The timing. OpenAI states no refresh schedule. Google, by contrast, moved the refresh of its crawler address files from weekly to daily in March 2025.
The Merj alert, and an earlier one
Ryan Siddle, managing director at Merj, posted the alert on LinkedIn today. The image in his post shows a message from Merj's "SEO/AEO IP Verification Monitor", reading "IP Range changes detected for source: openai-chatgpt-user", followed by a list of "Added IPv4 Ranges".
"I think something big is about to happen with OpenAI/ChatGPT," Siddle wrote. "We've just seen 2,064 new IP addresses added today across 129 of /28 blocks." He added that the last change of this size came with Apple and Siri about three months earlier, followed by other ChatGPT increments. PPC Land has not verified the earlier ChatGPT increments he refers to.
The Apple episode is on record. Applebot is the crawler that feeds Spotlight, Siri and Safari. On August 17, 2026, PPC Land reported that Apple added 4,656 addresses to its crawler's list in a single update, a change also spotted by Merj's monitor. Two months before that, Apple had rewritten its crawler documentation to say crawled data may help train Apple's foundation models. The two episodes share a pattern: an unannounced change in a public file, found by a third party, with timestamps that do not settle exactly when it happened. In August, the Applebot file carried a creation time of July 31, while public reports appeared on August 17.
Applebot figures come from PPC Land's August 17, 2026 report. ChatGPT-User figures are PPC Land calculations, with Merj's counts shown where they differ.
By that measure, the Apple change was larger: more than twice as many addresses, and nearly a tripling of the list. The ChatGPT-User change is larger in the number of separate blocks.
The comments under Siddle's post turned to timing. "Black Friday shopping in the US? Infra upgrade for the forecasted demand?" wrote Victor Pan, an SEO consultant. In a later reply he noted that "some deals are day-of only. Lots of procrastinators." Jonathan Alford, founder of Roboto, wrote: "Unoptimised infra melting-down is on my 2027 bingo card. Crawlers are going to go HARD". None of these readings comes from OpenAI.
Why a list of numbers matters to marketers
For most marketers, an address file sits several layers below daily work. It shapes three things they do look at.
The first is measurement. Server logs and AI visibility tools increasingly count ChatGPT-User visits as a sign that ChatGPT is reading a brand's pages while answering questions. Those counts depend on telling real visits from fake ones. A visit from one of today's new addresses, checked against yesterday's list, looks like a forgery.
The second is access. Bot management services decide, request by request, whether to allow, challenge, slow down or block automated traffic. Rules that allow ChatGPT-User only from listed addresses treat everything else as suspect. When a site's copy of the list lags, legitimate visits can be challenged or blocked, and ChatGPT may then answer without that page.
The third is fraud. Borrowing a famous bot's name costs almost nothing. Google's Gary Illyes said in October that faking Googlebot takes about 30 seconds. In August, GreyNoise found scanners posing as AI crawlers from 824 addresses, hunting for passwords and keys; none of those addresses matched the published lists of Anthropic, OpenAI, Google, Perplexity or Amazon. The published lists were what exposed them. The reverse problem exists too: in December 2025, DataDome documented a single Grok page request that produced 16 requests from 12 addresses, none identifying as xAI.
Lists can also trail real traffic. In July 2026, developers on OpenAI's community forum reported ChatGPT app requests from addresses missing from a different OpenAI file, chatgpt-connectors.json, which had last been updated on June 24. The file was regenerated on July 8 to cover them. One reply in the thread described OpenAI's ranges as best effort and recommended certificate-based checks instead of address allowlists; the forum page does not show whether that poster works for OpenAI.
Signed requests are one alternative to address lists. Arkose Labs found that ChatGPT agent signed 78.4% of its sessions with Web Bot Auth, a method in which each request carries a cryptographic signature. OpenAI's documentation for ChatGPT-User, as read today, mentions only the address file.
